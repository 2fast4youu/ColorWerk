# ColorWerk

**Deutscher, unabhängiger Fork von [LuckyTool](https://github.com/luckyzyx/LuckyTool) für ColorOS.**

## Download

➡ **[APK unter GitHub Releases herunterladen](https://github.com/2fast4youu/ColorWerk/releases)**

➡ **[Deutsche Anleitung, Voraussetzungen und Build-Beschreibung](README_DE.md)**

ColorWerk übersetzt die Benutzeroberfläche von LuckyTool ins Deutsche und verwendet einen eigenen App-Namen, eine eigene Paketkennung (`at.gregor.colorwerk`) und eine eigene Signatur. Die zugrunde liegenden ColorOS-Funktionen stammen aus dem Originalprojekt.

### Funktionen

- Statusleiste, Uhr, Netzwerkgeschwindigkeit und Kontrollzentrum anpassen.
- Sperrbildschirm, Always-on-Display, App-Symbole und Launcher gestalten.
- Schwebende Fenster, Systemdialoge, Installation und weitere Systemfunktionen konfigurieren.
- Erweiterungen für Kamera, Galerie, Spieleassistent und weitere ColorOS-Apps.

### Wichtig

- Benötigt ein kompatibles ColorOS-Gerät, LSPosed/Xposed und teilweise Root.
- Nicht gleichzeitig mit LuckyTool für dieselben System-Apps aktivieren.
- Die APK ist **kein direktes Update der Original-App**. Einstellungen werden nicht automatisch übernommen.
- Ein erfolgreicher Build und Ressourcenprüfungen sind kein Nachweis für die Funktion sämtlicher Hooks auf einem realen Gerät. Geräte- und Firmwareunterschiede beachten.
- Der erste Übersetzungsentwurf wurde lokal maschinell erstellt und um manuelle Korrekturen ergänzt. Sprachliche Verbesserungen sind willkommen.
